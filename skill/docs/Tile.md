The only card shape. Fill, radius, no border.

```jsx
<Tile tone="dark" label="Safe to spend"><StatBlock size="xl" value="227 400" /></Tile>
<Tile tone="alarm" label="Needs a decision">…</Tile>
```

`dark` is reserved for the single most important figure on a page. Wash tones (`alarm`, `info`, `caution`) carry state, never decoration.
