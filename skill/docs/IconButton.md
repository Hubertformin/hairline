A round icon-only button for navigation chrome and composers.

```jsx
<IconButton label="Search" tone="quiet">{searchGlyph}</IconButton>
<IconButton label="Send" tone="solid" size={40}>{arrowGlyph}</IconButton>
```

Pass a 24×24 stroke SVG with `stroke="currentColor"`. `bare` is for a glyph inside a field.
